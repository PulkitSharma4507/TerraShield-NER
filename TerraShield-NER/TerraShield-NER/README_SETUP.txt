SLOPEGUARD NER - READY-TO-RUN ML MVP
====================================

WHAT THIS PACKAGE DOES
----------------------
1. Uses your landslides_NER_clean.csv (10,318 historical events).
2. Converts the historical points into 0.1-degree spatial cells.
3. Trains a Random Forest on:
       latitude cell + longitude cell
4. Treats cells containing historical landslides as positive examples
   and empty background cells as negative examples.
5. Creates district-level locations.json from the CSV.
6. Provides a Flask API at http://127.0.0.1:5000/predict.
7. Provides a replacement script.js that loads the district map and
   connects clicks to the AI API.

IMPORTANT SCIENTIFIC NOTE
-------------------------
This is a HISTORICAL SPATIAL SUSCEPTIBILITY prototype.
Your CSV does NOT contain rainfall, soil moisture, slope, elevation,
or a future landslide/no-landslide target.

Therefore this model should NOT be presented as a fully real-time
physical landslide predictor yet.

For the final system, add:
    rainfall
    soil moisture
    slope/elevation
    satellite features
    weather forecasts
and retrain a multimodal model.

SETUP
-----
1. Copy landslides_NER_clean.csv into the ml folder.

2. Open VS Code terminal.

3. Install packages:
       cd ml
       python -m pip install -r requirements.txt

4. Train:
       python train_model.py

5. Generate district map data:
       python create_locations.py

6. Start API:
       python app.py

   Keep this terminal running.

7. Start your existing frontend with Live Server.

8. Open index.html through Live Server.

9. Click a district marker.
   The dashboard will call:
       POST http://127.0.0.1:5000/predict

10. Open browser DevTools Console if you want to see the AI response.

WHAT CHANGED IN YOUR DASHBOARD
------------------------------

- Rainfall / Soil Moisture / Slope show N/A because those fields
